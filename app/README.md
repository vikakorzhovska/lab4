# Генератор карток для повторення

Перетворює текстові нотатки на 5 карток «питання-відповідь» за допомогою локальної моделі через Ollama.

## Що потрібно
1. Python 3.10+
2. Ollama (https://ollama.com/download)
3. Бібліотека: py -m pip install openai

## Запуск
1. Завантажити модель: ollama pull qwen3:1.7b
2. Переконатися, що Ollama працює (іконка в треї).
3. Покласти нотатки у notes.txt (або вказати свій файл).
4. Запустити: py flashcards.py notes.txt
   (на системах, де працює команда python: python flashcards.py notes.txt)

## Параметри генерації
- temperature 0.3: стабільний JSON із трохи різними формулюваннями
- max_tokens 700: запобіжник від зациклення
- контекст 4096 токенів
- режим міркування вимкнено, таймаут 300 с

## Рекомендовані налаштування Ollama (необов'язково)
Змінні середовища користувача, після зміни перезапустіть Ollama:
- OLLAMA_FLASH_ATTENTION=1
- OLLAMA_KV_CACHE_TYPE=q8_0
Це зменшує пам'ять з 1,9 до 1,7 ГБ (див. звіт у ноутбуці).
